# Dada Todo 安装包

当前版本 0.2.10（源码 fulvaz/dada-todo@769fc53），由 GitHub Actions 自动发布，只保留最新一版。

- Mac（Apple 芯片）：[Dada-mac.dmg](https://raw.githubusercontent.com/fulvaz/dada-todo-releases/main/Dada-mac.dmg)。第一次打开要在「系统设置 → 隐私与安全性」点「仍要打开」，之后 App 自己更新。
- 安卓：[Dada-android.apk](https://raw.githubusercontent.com/fulvaz/dada-todo-releases/main/Dada-android.apk)。安装时允许浏览器「安装未知应用」。有新版本时 App 会提示下载。
- iPhone / iPad：用 Safari 打开 https://dada-todo.vercel.app ，点分享按钮 →「添加到主屏幕」。网页发版后自动是新版。
